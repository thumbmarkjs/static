How to use it

  1. Reload drift — Run, then reload the page. The L column compares against the previous load in this tab.
  2. Private browsing — Run here, Copy, open a private window, paste into Paste / import, Run. The C column is the cross-context diff.
  3. A different screen — Run, Pin as baseline, drag the window to another monitor, reload, Run. The B column survives reloads and new tabs.
  4. iframe vs main window — the F column is filled automatically on every run.
  5. Mobile — open this page on a phone and compare against a desktop run via Copy / Paste.

Expect R to always match. Two evaluations in one page load differ only if a signal is non-deterministic — clockGranularityMs is the one signal for which that is by design. Anything else showing R:diff is a bug worth reporting.
